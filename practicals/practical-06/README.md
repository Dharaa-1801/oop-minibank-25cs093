# Practical 6 — Interfaces, packages, and runnable JAR

Give the project a maintainable package structure and executable build.

## Requirements

- Add `Transactable`, `InterestBearing`, `WithdrawRule`, and `Premium`.
- Use a default yearly-interest method.
- Demonstrate both an anonymous class and a lambda rule.
- Organise code into `model`, `util`, and `service` packages.
- Use a static import.
- Build and run the application as a JAR.

## Checkpoint

`java -jar target\oop-minibank-25cs093-1.0.jar` starts MiniBank.
