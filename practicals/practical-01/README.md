# Practical 1 — Project setup and menu shell

Create the MiniBank project and a console menu.

## Requirements

- Set up JDK 17+ and a private Git repository.
- Create `MiniBank` with `main`.
- Add the `BankInfo` record with `name` and `branch`.
- Add the `MenuOption` enum: `OPEN_ACCOUNT`, `DEPOSIT`, `WITHDRAW`,
  `TRANSFER`, and `EXIT`.
- Read the menu choice with `Scanner`.
- Use a switch expression and repeat until `EXIT`.

## Checkpoint

The program prints the bank header, shows the menu, handles placeholders, and
prints a goodbye message.
