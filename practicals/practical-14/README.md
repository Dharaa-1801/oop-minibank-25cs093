# Practical 14 — Final integration and delivery

Assemble every previous practical into the finished MiniBank.

## Requirements

- Create `BankService` using `Repository<Account>`.
- Connect validation, commands, exceptions, transactions, persistence, and
  reporting.
- Make the Practical 1 menu call real banking operations.
- Add safe batch processing.
- Complete unit tests for normal and failure cases.
- Build the runnable JAR and verify the final application.

## Checkpoint

The complete MiniBank can open accounts, deposit, withdraw, transfer, show
statements, list accounts, and generate a report.
